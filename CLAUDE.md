## Что за проект

**StarBoy** — носимый AI-аксессуар (брелок/кулон) с встроенным круглым AMOLED-дисплеем, на котором живут анимированные глазки. Устройство работает как «цифровой питомец» с характером: слушает голос, отвечает через ИИ, реагирует на тряску, погоду и присутствие других StarBoy рядом.

**Концептуальный референс:** StarBoy от hesjustalittleguy.com — у них акцент на жизнь без интернета, обмен «глазами» между устройствами через Bluetooth, ювелирное качество корпуса. Мы делаем похожее, но с **главным отличием — встроенный AI для разговоров** (через облачный API, локально модель не помещается).

**Эстетика корпуса:** чёрный глянцевый обсидиан, амбер-glow в глазах как единственная цветовая нота, swiss horological mood. Кодовое название стиля — «Obsidian Mirror». Подробности в `design/PHILOSOPHY.md`.

**Форма первого прототипа:** 8-конечная звезда (Stella Octangula). Габарит ~95мм. Со временем планируется линейка форм: 4-конечная звезда (Guardian), цветок (Joyful), кролик (Tender), сердце (Romantic), круг (Silent) — каждая со своим характером и системным промптом для AI.

## Железо

### Основная плата
**Waveshare ESP32-S3-Touch-AMOLED-1.32**
- ESP32-S3-PICO-1-N8R8 (двухъядерный Xtensa LX7, до 240 МГц)
- 8 МБ PSRAM, 8 МБ Flash
- Wi-Fi 2.4GHz, Bluetooth 5 LE
- AMOLED 1.32" 466×466, контроллер CO5300 через QSPI
- Тач CST820 через I2C
- Аудиокодек ES8311 через I2S
- Встроенный микрофон
- Управление питанием для Li-Ion 3.7V (MX1.25 разъём)
- Разъём для динамика 8Ω 2W
- Расширение: SH1.0 12-pin (включает GPIO0, GPIO1, GPIO2, I2C SDA/SCL, USB, UART, питание)
- Диаметр платы: ~38мм

### Распиновка (важно — сохранить)
```
Display CO5300 (QSPI):
  LCD_RESET: GPIO8
  LCD_TE:    GPIO9
  LCD_CS:    GPIO10
  LCD_SCL:   GPIO11
  LCD_D0..3: GPIO12, 13, 14, 15

Touch CST820 (I2C — общая шина с расширением):
  Interrupt: GPIO6
  Reset:     GPIO7
  I2C_SDA:   GPIO47
  I2C_SCL:   GPIO48

Audio ES8311 (I2S):
  ASDOUT:  GPIO40
  LRCK:    GPIO41
  DSDIN:   GPIO42
  MCLK:    GPIO38
  SCLK:    GPIO39
  PA_CTRL: GPIO46
  Codec I2C SDA: GPIO47
  Codec I2C SCL: GPIO48

Кнопки:
  PWR:  GPIO17
  BOOT: GPIO0

Свободные GPIO (выведены на 12-pin):
  GPIO0, GPIO1, GPIO2 (плюс уже занятые I2C для расширения сенсоров)
```

### Что докупаем
- **Гироскоп+акселерометр**: LSM6DS3 (предпочтительно — точнее) или MPU6050. Подключение по I2C на ту же шину GPIO47/48.
- **Динамик**: 8Ω 2W, MX1.25 разъём
- **Литий-полимерный аккумулятор**: 3.7V, MX1.25 разъём, ёмкость на выбор
- **Кабель SH1.0 12-pin** для будущего расширения
- **Камера**: OV2640 — отложена. На этой плате нормально подключить параллельную DVP-камеру практически невозможно (12-pin разъём не вытянет 12+ пинов камеры). Решение откладывается до Этапа 7+.
- **GPS**: тоже отложен до отдельной серии «детских» моделей.

## Архитектурные решения, принятые

1. **AI — гибридная архитектура.** Локально на ESP32-S3 LLM не помещается (8МБ PSRAM мало). Локально делаем wake-word detection через `esp-sr` от Espressif. Полный диалог идёт через облачный API: микрофон → I2S → ESP32 → Wi-Fi → STT (Whisper или аналог) → LLM (Claude/GPT/Gemini, провайдер пока не выбран) → TTS (ElevenLabs или аналог) → I2S → динамик.

2. **Личность через системный промпт.** Каждая модель/серия — это отдельный системный промпт для LLM. Никакого fine-tuning, всё на prompt engineering.

3. **Форма = характер.** Линейка форм корпуса напрямую кодирует характер модели (звезда=дерзкий, кролик=нежный и т.д.).

4. **Глазки — главный UI.** На дисплее по умолчанию рендерятся анимированные глазки. Текст и иконки — минимально, только при необходимости. Глазки реагируют на акселерометр (зрачки следят за наклоном), на громкость окружения, на касания.

5. **Bluetooth-вирус.** Когда два StarBoy рядом — обмен глазами/поведением через BLE. Это фишка, которую внедряем после стабилизации основы.

6. **Корпус.** Задняя часть круглая (под плату 38мм), передняя — декоративная любой формы. Минимальная толщина устройства ~14мм с учётом аккумулятора.

## Принципы кода для этого проекта

- **Модульность.** Каждая подсистема (display, eyes, audio, sensors, wifi, ai, ble, power) — отдельная папка/класс. Не помойка из main.cpp.
- **FreeRTOS-задачи.** Дисплей, аудио, сетевой стек — параллельные задачи с правильными приоритетами. Не блокирующий main loop.
- **PSRAM.** Буферы кадров (466×466×2 = ~434КБ на кадр) — обязательно в PSRAM. Внутренней SRAM не хватит.
- **Без секретов в коде.** Wi-Fi пароли, API-ключи — через `secrets.h` который в `.gitignore`. В репо коммитится только `secrets.example.h`.
- **Английский в коде.** Комментарии, имена, коммиты — английский. Общение с пользователем — русский.
- **Не оптимизировать преждевременно.** Сначала рабочий MVP, потом профилирование, потом оптимизация.
